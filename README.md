## 为什么不做「限时 / 锁 App」

只做减法没用——锁出来的空白会立刻被原来的行为重新填满。这款产品不争一整天，只争**伸手解锁、准备下滑的那 3 秒**：把一次无意识滑动，变成一次有意识选择，同时给一个启动成本更低的加法。

三条铁律：

1. **自己必须最省时**：单次交互 ≤10 秒，完成即退出，不做信息流、社区、排行榜。
2. **不阻断当下这一段，但续段要付费**：把「再点一下」改成「再做一件事」。
3. **只记换回来的**：界面不显示「刷了多久」，只显示换回的时间和攒下的思考卡片。

## 核心机制：强制闸门（V3）

- 第一次由你决定：点桌面任意短视频 App → 3 秒清醒窗口 → 可「先看 5 分钟」，也可直接做一件 2–3 分钟的事。
- **额度到点，系统强制收起视频界面**，进入「已收起」页。这一页**没有任何继续按钮**。
- 想再开一段，只有一条路：完成一次置换（写一句话 / 动一动 / 联系一个人）→ 得到一张「下一段额度券」→ 立即兑现或攒着不看。
- 规则一句话：**一段视频 = 一次置换**。

防绕过的四条：

| 绕过方式 | 处理 |
|---|---|
| 换到快手、小红书继续看 | 8 个平台整组锁定，桌面图标全部灰化加锁角标 |
| 到点前主动「一键收手」再重开 | 同样按用掉一段处理，仍进闸门 |
| 先攒一堆额度券 | 首次清醒窗口完成置换不预先发票 |
| 被关到想卸载 | 每天 1 次紧急放行，需二次确认，且只是例外、不解除闸门 |

设置页提供 **严格**（默认）/ **柔和** 两档，柔和档到点只弹清醒窗口、可一键续段，便于循序渐进。

## 平台按「钩子类型」分三组

| 分组 | 平台 | 回收节拍 |
|---|---|---|
| 无限下滑型 | 抖音、快手、视频号、微视 | 5 分钟 / 段 |
| 连续剧集型 | 红果短剧 | 按集间提醒，不打断剧情 |
| 兴趣社区型 | 小红书、哔哩哔哩、西瓜视频 | 10 分钟 / 段 |

短剧不在剧集中间弹窗，是刻意的：它的钩子是「下一集」，集末才是天然断点。

## 页面与数据

手机模拟器 + 左侧演示引导 + 右侧控制台，共 12 个可点状态：桌面、清醒窗口、强制收起页、动脑 / 动身 / 联系、完成反馈、视频额度中、留白账本、思考卡片、每周回顾、设置。数据落 localStorage，刷新不丢。

北极星指标是**置换率**（完成置换 / 清醒窗口曝光），不是屏幕时长；后者只是滞后结果，用它当核心指标会滑回「监控 / 羞辱」叙事。

## 双端落地边界

- **iOS 能做到真强制**：`FamilyControls + ManagedSettings` 的 Application Shield 可对整组 App 生效，图标变暗、打开只见自定义屏蔽页；`ShieldActionExtension` 的按钮经 App Group 通知主 App 清除 shield，正好实现「做完置换才解锁」。授权需向 Apple 单独申请。
- **Android 只能近似**：`UsageStatsManager + 悬浮窗` 无法真正阻止 App 启动，只能全屏遮罩模拟「收起」；硬阻断需无障碍 / 设备管理器，Google Play 政策受限，国内渠道可评估。额度到点靠前台服务触发，国内 ROM 保活是主要不确定性。
